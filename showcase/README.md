# Gesture Lab — Showcase cover

![Gesture Lab spatial prototype](gesture-lab-cover.png)

This cover is an authentic 1600 × 1000 screenshot of the `/spatial-lab` WebGL prototype, captured in a browser review on 11 November 2026. The webcam was not running; no person's camera feed appears in the image.

To try this development version, use the `design/spatial-lab-cinematic` branch. A known issue is being investigated: gesture controls may become unresponsive with Debug OFF. Keep Debug ON during live demonstrations for now; this displays the local webcam/landmark preview.
